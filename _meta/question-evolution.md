# Question Evolution

## v1 (original)
How can we extend and improve the base paper's measurement of intersectional bias (SES × dialect × tone) in LLMs by adding causal analysis, longitudinal tracking, mitigation testing, and a deployable artifact?
→ **Died:** Budget constraint ($0)

## v2 (CONSIST)
Can self-consistency disparity — the difference in output variability across matched demographic prompt pairs — serve as a zero-cost unsupervised proxy for intersectional bias?
→ **Died:** Empirical falsification (CDS ≈ 0, p = 0.66)

## v3 (current — Divergent Representations)
What does the way an LLM generates text reveal about how it represents different demographic groups — and can we build a multi-signal behavioral profile from a single generation pass?
→ **Status:** Active
